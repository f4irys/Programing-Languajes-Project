Interactive Programs

Each card is a small web application connected to a course paradigm.

01 · Imperative · Python / PyScript

UPRM GPA Calculator

Add as many courses as you want. Choose the letter grade and credits for each course to estimate a semester GPA.

Estimated GPA will appear here.

02 · Functional · Elm

Study Session Timer

A functional Elm timer for focused study sessions and short breaks.

03 · Logical · Prolog / Tau Prolog

Career Path Advisor

Select your interests and Prolog rules will infer one or more possible career directions.

Career suggestion will appear here.

04 · Object-Oriented · TypeScript

Mini Smart Academic Task Planner

Create academic tasks using TypeScript classes and organize them by priority.

05 · Free Choice · JavaScript

Flashcard Generator

Create quick study cards for programming concepts.

06 · Free Choice · JavaScript

Internship Application Tracker

Save internship applications, update their status, filter the list, and keep the data in your browser.

Your applications are saved locally in this browser.

Dynamic Résumé / CV Program

This program reads CV data from a JSON file named cv, prints a résumé in HTML, allows entries to be included or excluded, and generates a PDF download.

Include in Résumé

Load the résumé to see controls.

Click “Load Résumé” to generate the CV from the JSON file.

Built with HTML, CSS, Python/PyScript, Elm, Prolog, TypeScript, JavaScript, and JSON.
